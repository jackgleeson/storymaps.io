Run it on your own server

Storymaps.io is an open source user story mapping tool, under AGPL-3.0. It's one Docker container behind Caddy, with HTTPS set up for you. The CLI works with it the same way: give it your site once.

  • AGPL-3.0
  • One container
  • HTTPS included
Self-hosting guide on GitHub Use the CLI with your own server

Every story map is data

Add .json, .yaml or .csv to the end of any story map link for its data, always as it is right now. There's no export step and nothing to keep in sync.

  • storymaps.io/abc12345.json
  • storymaps.io/abc12345.yaml
  • storymaps.io/abc12345.csv
