User story mapping for Jira

4 min read

On this page
Import through the API Import a CSV file Review the import What you get on the story map Export to Jira

Bring a Jira backlog in, lay it out as a journey, then send the plan back. Epics, stories, statuses and story points all come with it, and every card links back to its issue.

  1. 1Jira API fetches the project straight from Jira.
  2. 2Jira CSV reads a CSV file exported from Jira.

Import through the API

  1. 1Choose Menu → Import → Jira → Jira API, or click Jira on the home page.
  2. 2Fill in the Jira Instance URL, such as your-team.atlassian.net, and the Project Key, such as PROJ.
  3. 3Add your Email and an API Token. The Get token link opens the page in Atlassian where you make one.
  4. 4Click Fetch from Jira. Verify Connection checks the details first, if you want to.

The API brings in the epics and stories of the project, in rank order. Stories with no epic go in a group called Other.

Note. Your credentials aren't stored or logged. They go straight to Jira and are dropped when you're done.

Import a CSV file

  1. 1In Jira, export the issues as CSV with all fields. The import dialog shows the way: Issues > ... > Export > CSV (all fields).
  2. 2In the story map, choose Menu → Import → Jira → Jira CSV.
  3. 3Drop the file in, or click to pick it.
  4. 4Add your Jira instance URL if you want each card to link back to its issue.
  5. 5Click Continue.

The file needs the Summary, Issue key and Issue Type columns. Every issue that isn't an epic comes in under its parent epic. Issues with no parent go in Other (no parent epic).

Review the import

Review Import lists every epic with its stories. Untick anything you don't want, or click Deselect all and tick what you do. The count at the bottom shows what's going in.

Importing into an open story map gives you a choice:

  • Add to existing map puts the imported cards to the right of what's there.
  • Replace map swaps the whole story map for the import, and asks first.

Either way, a backup is taken before anything changes. Click Import to Map to finish.

What you get on the story map

The cards land in a slice called IMPORTED: Epics & stories, with an empty MVP slice above it and a blank backbone.

  • Epics become lime green cards, tagged epic-01, epic-02 and so on.
  • Stories become cards tagged with their epic, such as epic-01-task, plus their Jira labels.
  • Descriptions go in the body of the card.
  • Statuses become done, in progress or planned.
  • Story points become the points on the card.
  • Links open the issue in Jira.

The cards fill up to eight columns from left to right, so an epic and its stories won't share a column. The tags keep them together: search and filter by epic-01 to see one epic at a time.

Tip. Now make it a story map. Name the users, activities and steps, then drag each card under the step it belongs to. Define the story map backbone shows how.

Export to Jira

Choose Menu → Export → Jira, then Jira CSV or Jira API. Both work the same way to start:

  1. 1Under Releases, tick the slices to send.
  2. 2Under Status, tick the statuses to send.
  3. 3Each step becomes an epic, named after the step, with its cards under it. Rename an epic, add a description, or untick anything to leave out.

A card body becomes the description of its issue.

Jira CSV

  1. 1Fill in the Project Name, Project Key and Project Type to import into an existing Jira project, or leave them blank to choose in Jira.
  2. 2Under Status Mapping, match each status to a Jira status. To start with, no status, planned and blocked match To Do, in progress matches In Progress, and done matches Done.
  3. 3Each epic can go out as an Epic or a Task. The cards under it go out as tasks.
  4. 4Click Download CSV, then import the file in Jira. The (How to import) link opens the Atlassian guide.

Note. Jira doesn't link epics to their issues when it imports a CSV. To keep the links, use the API.

Jira API

  1. 1Click Step 2: Credentials →.
  2. 2Fill in the Jira Instance URL, Project Key, Email and API Token.
  3. 3Click Export to Jira.

Each epic is created with its cards as stories under it, and the progress list links to every issue as it's made. Statuses don't carry over through the API. One export takes up to 200 epics and 2,000 stories.
