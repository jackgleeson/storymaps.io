User story mapping for Phabricator

4 min read

On this page
Import through the API Import a CSV file Review the import What you get on the story map Export to Phabricator

Bring Phabricator tasks in, lay them out as a journey, then send the plan back. Parent tasks, subtasks, statuses and points all come with them, and every card links back to its task.

  1. 1Phabricator API fetches the tasks straight from Phabricator.
  2. 2Phabricator CSV reads a CSV file exported from Maniphest.

Import through the API

  1. 1Choose Menu → Import → Phab → Phabricator API, or click Phabricator on the home page.
  2. 2Fill in the Instance URL, such as phabricator.example.com.
  3. 3Paste an API Token. How do I get this? shows where: click your profile picture, go to Settings, then Conduit API Tokens, then Generate Token.
  4. 4Add the Project Tags to import. Use the slug from the /tag/ URL of the project, or type the name with spaces, separated by commas.
  5. 5Click Fetch from Phabricator. Verify Connection checks the details first, if you want to.

A task with subtasks becomes a group, with its subtasks under it. Subtasks nested further down come in under the top-level task. Tasks with no parent and no subtasks go in a group called Other.

Note. Your API token isn't stored or logged. It goes straight to Phabricator and is dropped when you're done.

Import a CSV file

  1. 1In Phabricator, export the tasks as CSV. The import dialog shows the way: Maniphest > select tasks > Export as CSV.
  2. 2In the story map, choose Menu → Import → Phab → Phabricator CSV.
  3. 3Drop the file in, or click to pick it.
  4. 4Click Continue.

The file needs a Title column. A CSV doesn't say which task is the parent of which, so every task comes in on its own.

Review the import

Review Import lists every task. Untick anything you don't want, or click Deselect all and tick what you do. The count at the bottom shows what's going in.

Status, above the list, picks tasks by status: Planned, In Progress and Done. Done tasks are left out to start with. Tick Done to bring them in.

Importing into an open story map gives you a choice:

  • Add to existing map puts the imported cards to the right of what's there.
  • Replace map swaps the whole story map for the import, and asks first.

Either way, a backup is taken before anything changes. Click Import to Map to finish.

What you get on the story map

The cards land in a slice called IMPORTED: Phabricator tasks, with an empty MVP slice above it and a blank backbone.

  • Parent tasks become lime green cards, tagged epic-01, epic-02 and so on.
  • Subtasks become cards tagged with their parent, such as epic-01-task.
  • Descriptions go in the body of the card.
  • Statuses become planned for open and stalled tasks, in progress for tasks in progress, and done for the rest, such as resolved, declined and invalid.
  • Points become the points on the card. From a CSV, Final Story Points win over Points.
  • Links open the task in Phabricator.

The cards fill up to eight columns from left to right, so a parent task and its subtasks won't share a column. The tags keep them together: search and filter by epic-01 to see one parent task at a time.

Tip. Now make it a story map. Name the users, activities and steps, then drag each card under the step it belongs to. Define the story map backbone shows how.

Export to Phabricator

Choose Menu → Export → Phab, then Phabricator API or Phabricator Console API. Both work the same way to start:

  1. 1Under Releases, tick the slices to send.
  2. 2Under Status, tick the statuses to send.
  3. 3Each step becomes a parent task, named after the step, with its cards as subtasks. Rename a parent task, add a description, or untick anything to leave out.

Statuses carry over: no status and planned become open, in progress becomes progress, blocked becomes stalled, and done becomes resolved. A card body becomes the description of its task.

Phabricator API

  1. 1Click Step 2: Credentials →.
  2. 2Fill in the Instance URL and API Token, and add Project Tags so the tasks land in the right projects.
  3. 3Click Export to Phabricator.

The progress list links to every task as it's made. One export takes up to 200 parent tasks and 2,000 subtasks.

Phabricator Console API

The console export runs in your own browser, on your Phabricator site, so your API token never reaches Storymaps.io.

  1. 1Click Step 2: Import →.
  2. 2Fill in the Instance URL and API Token, and add Project Tags.
  3. 3Open your Phabricator site, open the browser console, then paste the first piece of code and press Enter. Copy copies it.
  4. 4Paste the second piece of code in the same console and press Enter to create the tasks.
