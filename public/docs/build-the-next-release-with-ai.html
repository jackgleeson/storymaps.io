Build the next release with AI

1 min read

On this page
Set it up Run it

Already have an app? Run a coding agent in the folder of your project and give it the next slice.

Try it now

Set up a build of the V1 slice of a coffee app.

Open practice story map

Set it up

Click Build, then choose:

  • Tool: a coding agent, such as Claude Code.
  • Storymap Slice: the next release, such as V1.
  • Build Mode: Add to Existing App. The prompt asks the agent to read the code first, keep what's there working and follow its conventions.
  • Additional Instructions: how you work, such as "Run the existing tests and add tests for each feature."

Run it

  • Claude Code, Codex and Gemini CLI: click Copy Command, and run it in your terminal from the folder of your project.
  • Cursor, Windsurf and GitHub Copilot: click Copy Prompt, and paste it into the agent chat in your editor.

The prompt covers every card in the slice, so say if some of it is already built.

Tip. Mark cards done on the story map once they're in the real product, so the team can see how the release is going.
