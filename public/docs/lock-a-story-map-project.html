Lock a story map project

2 min read

On this page
Lock it What a locked project does Lock or unlock one story map Unlock the project

A locked project keeps its name, user story maps and order as they are for everyone without the password. Use it for a project shared widely, such as a plan other teams follow.

Lock it

  1. 1Click the project name, at the left of the tabs, and click Lock project.
  2. 2Choose The project, or the option below it, to lock every story map in it too.
  3. 3Type a password of at least 4 characters and click Lock.

The project locks straight away, for you too. A story map that already has a lock keeps it, and the project box names any that weren't changed.

Tip. Keep the password somewhere safe, as it can't be recovered.

What a locked project does

Nobody can rename or delete the project, or add, remove or reorder its story maps, without the password. Add map shows a padlock.

Anyone with the link can still open every story map. A story map can still be edited unless it has its own lock, and a locked story map shows a padlock on its tab.

Menu → Copy this map makes a copy outside the project, as nothing can be added to a locked project.

Lock or unlock one story map

Each locked story map has a label in the project box:

  • Project lock means it uses the project password.
  • Map lock means it has a different password.

Unlock takes the lock off that story map for everyone, and Lock puts one on using the project password. The row asks for the password when it needs one.

To move a story map with a Map lock onto the project password, click Unlock and enter its own password, then click Lock.

Unlock the project

Click Unlock project in the project box, or click Add map, and type the password. The project stays unlocked for you until you close the tab. Everyone else still sees it locked.

The project box then has two more options:

  • Lock again locks it again in this tab.
  • Remove lock takes the lock off for everyone. Tick the box to remove the lock from story maps using the project password too. A story map with a Map lock stays locked.
