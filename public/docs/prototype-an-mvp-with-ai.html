Prototype an MVP with AI

1 min read

On this page
Set it up Learn from it Build it again

Get something people can click before anyone writes production code. A prototype of the first slice lets a product team build to learn: users try the whole journey, and the team sees what works before committing to the release.

Try it now

Prototype the MVP of a coffee app.

Open practice story map

Set it up

Click Build, then choose:

  • Tool: an app builder such as Lovable, or an AI chat.
  • Storymap Slice: MVP.
  • Build Mode: Prototype.
  • Additional Instructions: the look and who it's for, such as "Warm colours and big buttons for phones."

Click Copy Prompt and paste it into the tool. In an AI chat, the prototype comes back as a single HTML file that opens in a browser.

Learn from it

Put the prototype in front of users, and watch them go through it:

  • Can they get from the first step to the last?
  • Where do they stop or ask for help?
  • What do they expect that isn't there?

Add what you learn to the story map as new cards, under the step they relate to, and move cards between slices if the priorities change.

Build it again

With Include map URL on, the same prompt picks up those changes the next time you use it. Paste it in again and compare the new version with the last one.
