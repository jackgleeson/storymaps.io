Manage a story map project

1 min read

On this page
Rename the project Reorder the tabs Take a story map out Delete the project

Everything about a project is in the project box. Click the project name, at the left of the tabs, or choose Menu → Manage project.

  1. 1Name renames the project.
  2. 2Project link is the link that opens the project. Copy copies it.
  3. 3Each story map has a row to reorder it or take it out.
  4. 4Delete project deletes the project, and leaves the story maps alone.
  5. 5Lock project protects the project with a password. Lock a story map project covers it.

Rename the project

Type a new name in Name, then press Enter or click away to save it.

Reorder the tabs

Drag a story map by the handle at the left of its row, or use the up and down arrows. The tabs follow the order of the list.

Take a story map out

Click Remove and confirm. The story map isn't deleted and still opens at its own link.

Remove the last one and the project stays, with no tabs. Its link then offers to start a new story map in it.

Delete the project

Click Delete project and confirm. The story maps in it aren't deleted, but the project link stops working.

Tip. Anyone with the project link can rename, reorder and delete the project unless it's locked, so it's best shared with the people working on the product. Locking a story map doesn't lock the project it's in.
