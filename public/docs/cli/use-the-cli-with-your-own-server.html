Use the CLI with your own server

1 min read

On this page
Name the server in the link A new story map A server on your computer Any other address In the server logs

The CLI works with any Storymaps.io server, such as one your company runs. It goes to storymaps.io unless it's told otherwise.

Name the server in the link

Every command that takes a link takes one on your server:

The pulled file says where it came from, in its site line, so pull, push and the rest go back to the same server without the link:

A new story map

--site makes the new story map on your server:

A server on your computer

A server on your own computer always names its port, such as localhost:3000. It's reached over http:

The file then says site: localhost:3000, so every command finds the server. localhost on its own stops with a message asking for the port, so a command never goes to a port you didn't choose.

Any other address

Give the whole address, such as --site http://192.168.0.20:8080 or --site https://localhost:8443. The file names it in full, so every command after it uses the same address.

In the server logs

Each request from the CLI names it and its version, such as storymaps-cli/1.4.2, so the server logs can tell the CLI apart from other scripts.
