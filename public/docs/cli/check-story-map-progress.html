storymaps status shows how far the user story map has got: overall, slice by slice, and by status.

The story map in your file

After the push in Push changes to a story map:

  • Overall Progress counts the cards marked done against all the cards.
  • Slices does the same for each slice, with its points when cards have them.
  • Status counts the cards with each status.
  • Blocked shows only when a card is blocked, and lists each one by name.

Cards in a legend colour whose label doesn't say task, such as Notes or Questions, are left out of the counts.

Any story map, without a file

Give it a link to check a story map you haven't pulled:

It reads the story map as it is on the server, so it's up to date with changes made in the browser. Without a link, it reads your file, which may not be.

A whole project

In a project folder, it shows a line for each story map, in the order of the tabs, and a total:

When the project or its story maps are locked, each line ends with its lock. See Lock and unlock a project. Give it a project link, such as storymaps status storymaps.io/p/k8f2m9xq, to check a project you haven't pulled.
