Any story map

storymaps log shows the recent changes to the user story map, newest first. It's the same log as the activity log in the app.

Each line has the time, where the change came from and what it was:

  • >_ is the CLI, such as a push or a backup.
  • 🌐 is the browser, with the name of the person.
  • 📱 is a phone or tablet.

Changes from today show the time. Older ones show the date too.
