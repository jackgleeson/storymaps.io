Pull a story map

1 min read

On this page
Pull it Pull again Use another file name

storymaps pull downloads a user story map as storymap.yml, in the folder you're in, to edit and push back.

Try it now

The pages in this section follow one practice Coffee App. Open a copy, and use its link in the commands.

Open practice story map

Pull it

Give it the link of the story map:

storymaps pull [target] [-f <path>] [--force]

The link can be a whole address, such as https://storymaps.io/abc12345, or the ID on its own. A link to a project, or to a story map in one, such as storymaps.io/p/k8f2m9xq/abc12345, pulls into a storymaps folder instead. See Pull a project.

Pull again

Changes made in the browser don't reach the file by themselves. Run storymaps pull with no link to bring them in. The file knows which story map it came from.

It lists what changed, and asks before it overwrites the file. --force skips the question. If nothing changed, it says Already up to date.

Tip. Pull replaces the whole file, edits and all. Push or copy your own changes first.

Use another file name

-f pulls into a different file, so one folder can hold several story maps:

Most other commands take -f too, such as storymaps push -f checkout.yml. diff takes the file name on its own: storymaps diff checkout.yml.
