Hand a story map to an AI coding agent

2 min read

On this page
Let the app write the command Do it by hand A whole project Steer it a slice at a time Keep it up to date

A story map makes a good specification for an AI coding agent. storymap.yml lists every step of the journey and the cards under each one, slice by slice, so the agent can build a slice and know what comes later.

Let the app write the command

In the app, click Build and pick Claude Code, Codex or Gemini CLI, with Use npx storymaps ticked. Copy Command gives a command that pulls the story map, then starts the agent on it:

Run it in the folder the app should go in. See Build an app from a story map with AI for the choices in Build.

Do it by hand

Pull the story map, then start the agent with your own words:

A whole project

For a project of several story maps, pull the project, so the agent gets every story map as one specification:

Have the agent pass --yes to the CLI, so it never waits on a question. See Pull a project.

Steer it a slice at a time

Once the agent is running, ask for more in the same session:

  • "Now build search from the V1 slice."
  • "Add Group ordering from V2, and nothing else from that slice."
  • "Which cards in the MVP slice aren't built yet?"

Keep it up to date

storymap.yml is a copy of the story map at the moment it was pulled. When the plan changes in the browser, run storymaps pull before the next round, so the agent works from the story map as it is now.

To have the agent change the story map too, see Update a story map with an AI agent.
