Command reference

Every command and option. A target is a user story map: an ID, a link such as storymaps.io/abc12345, or a whole address. A link to a story map in a project works too. Left out, the command uses the story map in storymap.yml, or every story map in the project folder.

storymaps --help lists the commands, storymaps <command> --help shows one, and storymaps --version prints the version.

Commands

CommandWhat it does
storymaps initMake a new story map and its storymap.yml
storymaps openOpen the story map in the browser
storymaps pullDownload a story map, or a whole project
storymaps pushSend your changes to the story map
storymaps diffSee what changed before you push
storymaps statusShow progress by slice and by status
storymaps logShow the activity log
storymaps lockLock a story map with a password
storymaps unlockSave the password on this computer, or take the lock off
storymaps backupBack up a story map, or every story map in a project
storymaps backupsList the backups of a story map
storymaps restorePut a story map back to a backup
storymaps validateCheck a story map file without the server
storymaps convertTurn YAML into JSON, or JSON into YAML

storymaps project addAdd a story map to the project
storymaps project lockLock the project, or the project and its story maps
storymaps project unlockUnlock the project on this computer, or take its lock off

One story map or a whole project

storymaps <command> works on story maps: one, named with -f or a link, or every story map in the project folder. storymaps project <command> changes the project itself.

With no -f or link, a project in reach wins: the folder named with --dir, a storymaps folder below you, or project files in the folder you're in. With no project in reach, storymap.yml means one story map. See Pull a project.

Questions and passwords

Questions are only asked in a terminal. -y, --yes takes the usual answer, and --force answers the questions that guard against overwriting or removing something. Passwords are typed, remembered after an unlock, or taken from STORYMAPS_PASSWORD. See Use the CLI in scripts and CI.

storymaps init

Makes a new storymap.yml in the folder you're in, and the story map on the server. Never joins a project. See Create a story map from the terminal.

Syntax

Options

OptionWhat it does
-s, --site <site>The server to make it on, such as storymaps.yourcompany.com, localhost:3000 or http://192.168.0.20:8080. A server on your computer names its port. storymaps.io if left out.

Examples

storymaps open

Opens the story map in the browser, and prints its link. In a project folder, opens the project at its first story map. See Open a story map in the browser.

Syntax

Options

OptionWhat it does
-f, --file <path>The file to read the story map from.
--dir <folder>The project folder. storymaps if left out.

Examples

storymaps pull

Downloads the story map as YAML, or every story map in a project. Shows what changed and asks before it overwrites a file. See Pull a story map and Pull a project.

Syntax

Options

OptionWhat it does
targetA story map, or a project link such as storymaps.io/p/k8f2m9xq.
-f, --file <path>The file to write, for one story map. storymap.yml if left out.
--dir <folder>The project folder. storymaps if left out.
--forceOverwrite files without asking.
-y, --yesTake the usual answers, such as just the story map for a link to one in a project.

Examples

storymaps push

Sends the file to the story map, or every changed story map in a project. Stops if a story map changed since the last pull, and in a project checks everything before sending anything. See Push changes to a story map and Push changes to a project.

Syntax

Options

OptionWhat it does
-f, --file <path>The file to push, YAML or JSON, for one story map.
--dir <folder>The project folder. storymaps if left out.
--forceSkip the conflict check, and replace what changed on the server.

Examples

storymaps diff

Compares a file with its story map, or with another file, or every story map in a project with the server. See See what changed in a story map.

Syntax

Options

OptionWhat it does
sourceThe file to compare, or a link or ID to compare your file of that story map. storymap.yml if left out, or the whole project in a project folder.
targetA second file. Left out, it compares with the story map on the server.
--fullShow the changed lines, not only a summary.
--dir <folder>The project folder. storymaps if left out.

Examples

storymaps status

Shows progress overall, by slice and by status, and the cards that are blocked. In a project, a line for each story map with its lock, and a total. See Check story map progress.

Syntax

Options

OptionWhat it does
targetA story map or a project on the server, or a file.
-f, --file <path>The file to read, for one story map.
--dir <folder>The project folder. storymaps if left out.

Examples

storymaps log

Shows the activity log of one story map, newest first. See Read the activity log.

Syntax

Options

OptionWhat it does
-f, --file <path>The file to read the story map from. storymap.yml if left out.

Examples

storymaps lock

Locks one story map with a password of at least 4 characters, asked for twice. See Lock and unlock a story map.

Syntax

Options

OptionWhat it does
-f, --file <path>The file to read the story map from. Needed in a project folder.

Examples

storymaps unlock

Checks the password and saves it on this computer, so pushes and backups work. The story map stays locked for everyone else.

Syntax

Options

OptionWhat it does
-f, --file <path>The file to read the story map from. Needed in a project folder.
--removeTake the lock off for everyone.

Examples

storymaps backup

Backs up the story map on the server, or every story map in a project with the same note. Makes no new backup if nothing changed since one of them. See Back up and restore from the terminal.

Syntax

Options

OptionWhat it does
-f, --file <path>The file to read the story map from, for one story map.
--dir <folder>The project folder. storymaps if left out.
-m, --message <note>A note, to tell the backup apart later.

Examples

storymaps backups

Lists the backups of the story map, newest first, with the ID to restore each one by. In a project, the newest backup of each story map.

Syntax

Options

OptionWhat it does
-f, --file <path>The file to read the story map from, for one story map.
--dir <folder>The project folder. storymaps if left out.

Examples

storymaps restore

Puts one story map back to a backup, after backing it up as it is now. Changes the story map, not your file, so pull afterwards. In a project folder, the backup ID says which story map.

Syntax

Options

OptionWhat it does
backup-idThe ID of the backup, from storymaps backups.
-f, --file <path>The file to read the story map from.
--dir <folder>The project folder. storymaps if left out.
--forceRestore without asking first.

Examples

storymaps validate

Checks a YAML or JSON story map file, or every story map file in a folder, without the server. See Validate and convert story map files.

Syntax

Examples

storymaps convert

Turns a story map file from YAML into JSON, or from JSON into YAML.

Syntax

Options

OptionWhat it does
--from <format>yaml or json. Worked out from the file name if left out.
--to <format>yaml or json. yaml if left out.
--out <file>The file to write. Prints in the terminal if left out.

Examples

storymaps project init

Starts a project, with a first story map or one from each file, written to the storymaps folder. See Start a project from the terminal.

Syntax

Options

OptionWhat it does
--name <name>The project name. Untitled project if left out.
filesStory map files to start from. They're left as they are.
--dir <folder>Where to write the story maps. storymaps if left out.
-s, --site <site>The server to make it on. storymaps.io if left out.

Examples

storymaps project add

Adds a story map to the project: a new one, one from a file, or one that already exists. Works offline: the next push creates it.

Syntax

Options

OptionWhat it does
file or linkA story map file, or a story map by its link or ID. A new blank story map if left out.
--name <name>The name of a new story map. My Story Map if left out.
--dir <folder>The project folder. storymaps if left out.
--project <link>The project, when there's no project folder yet.

Examples

storymaps project lock

Locks the project, or the project and its story maps, the same two choices as in the app. See Lock and unlock a project.

Syntax

Options

OptionWhat it does
--mapsLock the story maps that aren't locked too, without asking. On a locked project, lock only those.
-y, --yesTake the usual answer: the project alone.
--dir <folder>The project folder. storymaps if left out.
--project <link>The project, when there's no project folder.

Examples

storymaps project unlock

Unlocks the project on this computer, or takes its lock off for everyone.

Syntax

Options

OptionWhat it does
--removeTake the lock off for everyone.
--mapsAlso unlock the story maps that use the project password, or with --remove, take their locks off.
-y, --yesTake the usual answers: the project only, and the story map locks kept.
--dir <folder>The project folder. storymaps if left out.
--project <link>The project, when there's no project folder.
