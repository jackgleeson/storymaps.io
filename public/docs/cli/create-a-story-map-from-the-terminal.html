Create a story map from the terminal

1 min read

On this page
Make one Offline On your own server

storymaps init makes a new user story map: a storymap.yml file in the folder you're in, and the story map it belongs to on the server.

Make one

The CLI prints the new file too. It's a starter story map, with one of each kind of card to type over:

From here, edit the YAML and push it, or open it in the browser and carry on there.

If the folder already has a storymap.yml, the CLI asks before it overwrites it.

Offline

With no connection, the file is still made, and the CLI says so:

The first push makes the story map on the server, adds its id to the file, and prints its link:

Any story map file without an id works the same way, such as one written by hand or by an AI agent.

On your own server

--site makes the story map on another Storymaps.io server, such as one your company runs. See Use the CLI with your own server.
