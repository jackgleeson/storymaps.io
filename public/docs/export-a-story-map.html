Export a story map

2 min read

On this page

Export saves the user story map as a file you keep. Use it to hold a copy outside the app, move a story map to another site, or work on it in a text editor or a spreadsheet.

Try it now

Export a practice story map and open the file.

Open practice story map

Export a file

Open Menu → Export and pick JSON, YAML or CSV under File.

The window shows the data, ready to use:

  • Copy to Clipboard copies it, to paste into a message, a ticket or an AI chat.
  • Download File saves it. The file is named after the story map, and you can change the name first.

Minify squeezes the JSON onto one line, for when size matters more than reading it.

Export works on a locked story map too.

Pick a format

  • JSON is the whole story map, exactly as the app saves it. It's the safest copy to keep.
  • YAML holds the same, laid out to read and edit by hand.
  • CSV lays the story map out as a grid, one column per step, to open in a spreadsheet.

All three keep the goal and target date of each slice, and whether it's complete or closed.

All three import back in with Menu → Import. Import a story map covers what each one keeps.

Backups go with it

A JSON or YAML export carries the backups of the story map, so they move with it to another story map or another site. A CSV export doesn't. Back up and restore a story map has more.

The story map as it is now

To get the data without exporting, add .json, .yaml or .csv to the end of the story map link. It always gives the story map as it is right now. Story map data links shows how.

From the terminal

storymaps pull saves the story map as YAML, and storymaps convert turns that into JSON. See Pull a story map.

A picture or a printout

For a picture of the story map, or a printed copy, see Share a story map.

To Jira, Asana, Phabricator or Linear

The integrations under Menu → Export turn the cards into tickets in a tracker. Each has its own page: Jira, Asana, Phabricator and Linear.
