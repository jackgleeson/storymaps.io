Import a story map

2 min read

On this page

Got a user story map saved as a file? Import it and carry on where you left off. Paste the data or drop the file, and the story map appears in place of the one you're on.

Try it now

Import into a practice story map. It opens as your own copy, so nothing you care about gets replaced.

Open practice story map

Import a file

  1. 1Open Menu → Import.
  2. 2Under File, pick JSON, YAML or CSV.
  3. 3Paste the data on the left and click Import JSON, Import YAML or Import CSV. Or drop a file on the right, or click there to pick one.

Ctrl+Enter imports pasted data too, or Cmd+Enter on a Mac.

An import replaces the story map

Importing swaps everything on the story map for what's in the file, and the app asks before it does. It makes a backup first, as Auto: before import, so you can get the old story map back from Menu → Backups. Undo works too.

Tip. To keep the story map you're on, start a fresh one with Menu → New and import into that.

A locked story map has to be unlocked before you can import into it.

Pick a format

  • JSON is the whole story map, exactly as the app saves it: every card, colour, status, slice, the legend, the notes and the backups.
  • YAML holds the same, laid out to read and write by hand. It's the format to write a story map in a text editor, or to have an AI tool write one for you.
  • CSV lays the story map out as a grid, one column per step, so you can work on it in a spreadsheet. It keeps the cards, slices, legend and notes, but not the backups.

The quickest way to see each format is to export a story map you know and open the file.

From the terminal

storymaps push sends a YAML or JSON file to the story map, and a file without an id makes a new story map. See Push changes to a story map.

Backups come too

Import a JSON or YAML file that holds backups and they're added to the story map, marked as imported so you can tell them apart from the ones it already had. Back up and restore a story map has more.

If the import fails

Files are checked before anything changes. If something's wrong, such as a slice that names a step that isn't in the list, the app says what, and the story map stays as it was.

From Jira, Asana, Phabricator or Linear

The integrations under Menu → Import turn a backlog into a story map. Each has its own page: Jira, Asana, Phabricator and Linear.
