Write user stories on a story map

1 min read

On this page
Open a card large Story buttons

The title of a card is short, so the user story map stays readable. The body holds everything else: a user story, how it should behave, what has to be true for it to be done.

Try it now

Write stories for the tasks of a coffee app.

Open practice story map

Open a card large

Hover over a card and click its ⤢. A new task opens large on its own when you add it.

  • The strip along the top shows the step and slice the card is in, and whether the slice is closed or complete.
  • The title is under it, up to 38 characters.
  • The body underneath can be as long as you need.
  • The line at the bottom shows the card's status, points, tags and link. Click Edit to change them or pick a colour.

A card with a body shows a small mark on the story map, so you can tell it has more inside. Close the large view with × or Esc.

Story buttons

Three buttons add a template to the body in one click:

  • As a, I want, So that adds a user story.
  • Given, When, Then adds a scenario, for how the feature should behave.
  • Acceptance criteria starts a list of what must be true for the story to be done.

Fill in each line after the starter words. Enter moves to the next line to fill in, and in a list it starts the next item.

Tip. Keep the title as the short name everyone uses for the task, and put the user story in the body. The story map stays easy to scan, and the detail is one click away.
