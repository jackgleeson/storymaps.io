User story mapping for Asana

3 min read

On this page
Import through the API Import a CSV file Review the import What you get on the story map Export to Asana

Bring an Asana project in, lay it out as a journey, then send the plan back. Sections, tasks, subtasks and what's complete all come with it, and every card links back to its task.

  1. 1Asana API fetches the project straight from Asana.
  2. 2Asana CSV reads a CSV file exported from Asana.

Import through the API

  1. 1Choose Menu → Import → Asana → Asana API, or click Asana on the home page.
  2. 2Paste a Personal Access Token. The Get token link opens the page in Asana where you make one.
  3. 3Paste the Project URL or GID, such as the link to the project list.
  4. 4Click Fetch from Asana. Verify Connection checks the details first, if you want to.

The API brings in the sections, tasks and subtasks of the project.

Note. Your credentials aren't stored or logged. They go straight to Asana and are dropped when you're done.

Import a CSV file

  1. 1In Asana, export the project as CSV. The import dialog shows the way: Project > ... > Export/Print > CSV.
  2. 2In the story map, choose Menu → Import → Asana → Asana CSV.
  3. 3Drop the file in, or click to pick it.
  4. 4Click Continue.

The file needs a Name column. Subtasks come in under their parent task, matched by name.

Review the import

Review Import lists every group with its tasks. Untick anything you don't want, or click Deselect all and tick what you do. The count at the bottom shows what's going in.

When the project has two or more sections, Tag by picks how the tasks group:

  • Group by sections makes each section a group, with its tasks under it. Subtasks aren't imported.
  • Group by tasks & subtasks makes each task a group, with its subtasks under it.

Importing into an open story map gives you a choice:

  • Add to existing map puts the imported cards to the right of what's there.
  • Replace map swaps the whole story map for the import, and asks first.

Either way, a backup is taken before anything changes. Click Import to Map to finish.

What you get on the story map

The cards land in a slice called IMPORTED: Sections & tasks, or IMPORTED: Epics & stories when grouped by tasks, with an empty MVP slice above it and a blank backbone.

  • Groups become lime green cards, tagged section-01 or epic-01 and so on.
  • Tasks under a group become cards tagged with it, such as section-01-task.
  • Notes go in the body of the card.
  • Complete tasks are marked done, and the rest planned.
  • Links open the task in Asana.

The cards fill up to eight columns from left to right, so a group and its tasks won't share a column. The tags keep them together: search and filter by section-01 to see one group at a time.

Tip. Now make it a story map. Name the users, activities and steps, then drag each card under the step it belongs to. Define the story map backbone shows how.

Export to Asana

Choose Menu → Export → Asana, then Asana CSV or Asana API. Both work the same way to start:

  1. 1Under Releases, tick the slices to send.
  2. 2Under Status, tick the statuses to send.
  3. 3Each step becomes a parent task, named after the step, with its cards as subtasks. Rename a parent task, or untick anything to leave out.
  4. 4Tick Also create Asana sections for parent tasks? to put each parent task in a section of the same name.

A card body becomes the description of its subtask.

Asana CSV

Click Download CSV, then import the file into your Asana project. The dialog shows the way: click the project name dropdown, then Import, then CSV.

Asana API

  1. 1Click Step 2: Credentials →.
  2. 2Paste a Personal Access Token and the Project Page URL.
  3. 3Click Export to Asana.

The progress list links to every task as it's made. Cards marked done are created complete. One export takes up to 200 parent tasks and 2,000 subtasks.
