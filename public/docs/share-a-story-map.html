Share a story map

1 min read

On this page
Share a project Share a slice or a task Print or save as PDF Who can change a shared story map

Every user story map has its own link, and anyone with the link can open the story map and work on it with you. Nobody needs to sign up.

  1. 1Share URL copies the link to the story map.
  2. 2Share as image copies a picture of the whole story map, to paste into a chat or a document.
  3. 3Download image saves the picture as a PNG file.
Try it now

Try the Share menu on a practice story map.

Open practice story map

Share a project

When a story map is in a project, the Share menu offers Share project link first. That link opens the project with all its story maps as tabs. Share this map link opens the story map you're on, with the tabs above it.

Share a slice or a task

A slice or a task has its own link too, which opens the story map right where it is. Plan releases with story map slices and Add tasks to a story map cover them.

Print or save as PDF

Choose Menu → Print. To save a PDF, pick Save as PDF as the printer.

Who can change a shared story map

Anyone with the link can edit the story map, and everyone sees changes as they happen. To share it without letting people change it, lock it from Menu → Lock Map (Read-only). A locked story map can still be viewed and shared.

Tip. Keep the lock password somewhere safe, as it can't be recovered.
